UNITR — Updates 4 June 2026
============================

## Venue Portal — Calendar & Settings

NEW: Venue Calendar page (/venue/calendar)
- Day view: each pitch shown as a colour-coded column, time slots 07:00–23:00
- Week view: 7-day columns with all pitches colour-coded and a pitch legend
- Full scrollable time grid (full operating hours visible, sticky headers)
- Tap any empty slot → pre-filled Add Booking modal (team name, date, start/end time, notes)
- Tap any booking block → view details, cancel option
- Platform bookings (from Unitr matchmaking) appear automatically alongside manual entries
- Today button + prev/next date navigation
- "Availability" nav item replaced with "Calendar" in venue bottom nav

UPDATED: Venue Settings page (/venue/settings) — now has 4 tabs
- Info: venue name, address, description, formats, surfaces, amenities
- Schedule: toggle each day open/closed, tap time to edit open/close hours
- Pricing: base hourly rate + pricing rules (e.g. Peak Evenings Mon–Fri 18:00–22:00 at £120/hr)
- Holidays: block specific dates whole-day or time-range with optional reason

SQL required:
  alter table public.pitch_bookings
    add column if not exists end_time text,
    add column if not exists booker_name text,
    add column if not exists notes text,
    add column if not exists booking_type text default 'platform';
  alter table public.pitches
    add column if not exists pricing_rules jsonb not null default '[]'::jsonb;


## Matchmaking — Booking Sync to Venue Portal

FIX: Confirmed matches now properly sync to the venue portal calendar and dashboard
- pitch_bookings insert in handleConfirm now sets booking_type="platform",
  booker_name="Team A vs Team B", end_time (start + 1hr)
- RLS on pitch_bookings disabled for MVP simplicity
- Date comparison made case-insensitive to handle "JUN" vs "Jun" format mismatch

FIX: Captains now included in match_confirmations on challenge confirm

  on top of approved team_members — ensures correct headcount for payment split
